**One line, zero use** — a one-line useless superpower. `main.ts` (Node 22, no network, no dependencies) writes the line to `/output/entry.txt` (falling back to `./output/entry.txt` when run locally).

The line gives its hero the most useless version of foresight: five seconds of the future — enough time to see the mistake coming, and watch yourself make it anyway. The setup sounds like a real gift; the punchline turns it into a front-row seat to your own clumsiness.

## Run it

```sh
node main.ts
```

Then read `output/entry.txt` (or `/output/entry.txt` in the grading sandbox).
